# Ngọc Rồng Online Web

MMORPG 2D chạy trên trình duyệt, chuyển đổi từ prototype Mèo Đa Vũ Trụ sang lối chơi Ngọc Rồng Online. Client dùng React, Phaser và Redux Toolkit; server dùng Node.js, Socket.IO và MongoDB. Server là nguồn xác nhận cho di chuyển, chiến đấu, quái, vật phẩm, bản đồ và tiến trình.

## Trạng thái dự án

## Chạy dự án

Cần Node.js và MongoDB. Cài dependencies từ thư mục gốc, cấu hình `.env` dựa trên `.env.example`, sau đó chạy:

```bash
npm install
npm run dev
```

Lệnh `npm run dev` khởi động client và server. Có thể chạy riêng `npm run dev:client` hoặc `npm run dev:server`. Chạy test server bằng `npm test`; lint/build client bằng `npm --prefix client run lint` và `npm --prefix client run build`.

Source NRO gốc được giữ trong `client/nro-source-archive/` (local, không commit). Build tái tạo các runtime asset được chọn từ danh sách map mở; catalog và hợp đồng Socket.IO dùng chung nằm trong `shared/nro/` và `docs/NRO_SOCKET_CONTRACT.md`.
